Desarrollo Cloud Native — Semana 4

Aplicación de demostración disponible en una EC2 con Docker, creada para probar la integración con AWS API Gateway y Azure AD B2C.

Comprobar /saludConsultar /datos

Ambas rutas están accesibles de forma directa en esta instancia, intencionalmente para la clase.

Demostración: después de comprobar el acceso directo, configura GET /datos en API Gateway con autorización. En la URL del Gateway la petición sin JWT deberá fallar, y con un access token válido podrá responder.
